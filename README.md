# Ads Online — бэкенд площадки для перепродажи вещей

Дипломный проект курса «Java-разработчик» Skypro. Бэкенд на Spring Boot для готового фронтенда
на React: пользователи регистрируются, размещают объявления с фотографиями и обсуждают их в комментариях.

## Возможности

- регистрация, вход по Basic-авторизации, смена пароля;
- просмотр и редактирование профиля, загрузка аватара;
- просмотр всех объявлений без авторизации;
- создание, редактирование и удаление своих объявлений, замена картинки;
- комментарии к объявлениям: создание, редактирование и удаление своих;
- роли USER и ADMIN: администратор может редактировать и удалять любые объявления и комментарии.

## Технологии

| Что | Зачем |
|-----|-------|
| Java 11, Spring Boot 2.7 | основа приложения |
| Spring Web | REST-контроллеры |
| Spring Security | Basic-авторизация, роли, проверка прав |
| Spring Data JPA, Hibernate | работа с БД через репозитории |
| PostgreSQL | основная база данных |
| Liquibase | миграции схемы БД |
| MapStruct | маппинг сущностей в DTO и обратно |
| Lombok | геттеры, сеттеры, конструкторы |
| Bean Validation | проверка входящих DTO по ограничениям спецификации |
| springdoc-openapi | документация API в Swagger UI |
| JUnit 5, MockMvc, H2 | unit-тесты мапперов и интеграционные тесты контроллеров |

## Структура проекта

```
ru.skypro.homework
├── config        настройка Spring Security
├── constants     общие константы
├── controller    REST-контроллеры
├── dto           объекты обмена с фронтендом по openapi.yaml
├── entity        JPA-сущности: пользователь, объявление, комментарий
├── exception     исключения и их перевод в HTTP-коды
├── filter        CORS-фильтр для Basic-авторизации
├── mapper        мапперы MapStruct
├── repository    репозитории Spring Data
├── security      пользователи из БД для Spring Security, проверка прав
└── service       бизнес-логика
```

Картинки сохраняются в папку из настройки `app.images.dir`, в БД хранится только имя файла.
Фронтенд получает картинку по пути `/images/{имя файла}`.

## Запуск

1. Создать базу данных в PostgreSQL:

   ```sql
   CREATE USER avito WITH PASSWORD 'avito';
   CREATE DATABASE avito OWNER avito;
   ```

2. Запустить бэкенд (таблицы создаст Liquibase):

   ```bash
   ./mvnw spring-boot:run
   ```

3. Запустить фронтенд в Docker:

   ```bash
   docker run -p 3000:3000 --rm ghcr.io/dmitry-bizin/front-react-avito:v1.21
   ```

4. Открыть http://localhost:3000. Документация API: http://localhost:8080/swagger-ui/index.html

## Тесты

```bash
./mvnw test
```

Интеграционные тесты поднимают приложение целиком на базе H2 и проверяют все эндпоинты,
включая права доступа для USER и ADMIN. Мапперы покрыты unit-тестами.
